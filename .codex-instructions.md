# Codex Instructions

Before coding:
1. Read `.ai/README.md`.
2. Read `.ai/ui.md`.
3. Read `.ai/stack.md`.
4. Read `.ai/rules.md`.
5. Read `.ai/roadmap.md`.
6. Read `.ai/learnings.md`.
7. Inspect the actual codebase before making changes.
8. Do not assume missing architecture.
9. If existing code conflicts with `.ai` documentation, report the conflict before changing major behavior.

After coding:
1. Update `.ai/roadmap.md` with completed work, affected files, remaining tasks, bugs, and next steps.
2. Update `.ai/learnings.md` if something worked, failed, or should be remembered.
3. Update `.ai/stack.md` only if architecture, tools, database, deployment, or authentication changed.
4. Update `.ai/rules.md` only if business behavior changed.
5. Update `.ai/ui.md` only if design rules or approved patterns changed.
6. Do not update global skills directly.
7. Add reusable patterns only under Candidate Global Skills.
8. Never write secrets, API keys, tokens, customer private data, or credentials into `.ai` files.
